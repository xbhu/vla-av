## Download Instructions

The data is **not stored in this repository** due to file size constraints.

Download from Zenodo: **[https://doi.org/10.5281/zenodo.XXXXXXX](https://doi.org/10.5281/zenodo.XXXXXXX)**

After downloading, place files as follows:

```
data/
├── raw/
│   ├── [file1.csv]
│   └── [file2.csv]
└── processed/
    └── [will be generated by preprocessing script]
```

To generate processed data from raw:

```bash
python src/utils/preprocess.py --input data/raw/ --output data/processed/
```
